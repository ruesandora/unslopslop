# Style packs

A style decides the look; a domain pack decides the constraints of the medium. When a user names a style ("make it retro pixel", "Swiss", "ASCII art"), the core skill loads `styles/<style>/README.md` and combines it with the domain pack (for example `retro-pixel` + `mobile`). With no style named, the direction comes from the project read alone.

Every pack has the same sections: defining traits, when it fits, palette combinations in our method, type with free licences, do/don't, its slop versions as detectable signs, tools as techniques.
