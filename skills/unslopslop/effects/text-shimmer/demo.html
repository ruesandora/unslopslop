Text shimmer

A light band that crosses a label while the system is working, then stops when the result arrives. The label keeps one solid colour and full contrast; a lighter copy of it is shown only inside the moving band, so screen readers, selection and contrast checks see plain text.

How it works
A pseudo-element repeats the label from a data attribute in a lighter colour and sits exactly on top. Its mask is a soft band three times wider than the label; animating the mask position from 100 to 0 percent moves the band from left to right in a straight line. Linear timing, because a sweep that eases looks like it hesitates.
Measured starting values
1.3 to 2.6 s per sweep, linear, infinite while pending. The lighter tone sits about 35 to 45 points of lightness above the ink on a light ground.
Cost
Mask position on one small layer: near zero. No script except the demo controls.
Reduced motion
The band is hidden and an ellipsis shows the pending state instead.
Becomes slop when
It runs on labels that are not waiting for anything, on headlines as decoration, or it never stops after the work is done. A gradient fill on the text itself is a different, flagged move: here the text keeps one colour.
