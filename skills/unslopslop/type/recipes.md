- Signature: The italic swap: one word of a roman display line set in the text italic at display size, so the line changes voice mid-sentence.
- Use when: Long reads, essays, publishers, cultural newsletters, any page whose job is to be read slowly.
- Turns into slop when: When every headline gets an italic word (it becomes a tic), when the italic word is also coloured (the coloured keyword tell), or when it heads a SaaS page that has nothing to say.
