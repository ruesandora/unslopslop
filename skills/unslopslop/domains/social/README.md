# Domain: Social and marketing visuals (posts, carousels, covers)

Status: **early**. Content is thin; extend it as references arrive.

## What good looks like
- One idea per slide, readable in one second on a phone; type large enough at 1080 x 1350 viewed at 390 px wide.
- A series system: the same grid, type and colour combination across slides, one element that moves forward from slide to slide.
- Real subject (product, person, data) over decoration.

## Workflow specifics
1. Brief plus the one takeaway; write the slide text first, 8 to 15 words per slide.
2. Build slides as HTML at their pixel size; screenshot each; review them side by side at phone size.

## Medium-specific slop signs
Gradient backgrounds with floating 3D emoji, "Here's why 🧵", ten bullets per slide, stock icons, every slide in a different style.

## Craft signals
A strong cover, rhythm across slides, one texture, consistent margins, a clear last slide.

## Deliverables
PNG per slide (1080 x 1350 or the platform size), the HTML source, caption text.

## Checks the detector runs
Web checks on each slide HTML (text size, contrast, overlap). Platform-specific checks are manual.

## Recipes
- **Family resemblance, content leads.** A set of four or five post templates that share type, colour and one geometric device; each post lets its content decide which element is biggest (the photo, the word, the shape). Show the set side by side before making more.
- **Two formats from one layout.** Design at 1080 x 1350 and 1080 x 1920 together; the shape or the photo absorbs the extra height, the type block does not move.
- **Signature shape as frame.** Put real photos inside the brand's shape (a disc, a letter counter) instead of on a plain rectangle; flat shape for recognition, photo-in-shape for appetite, a grid of shapes for quantity (board `../../../../inspiration/boards/signature-shape-system.html`).
- **Brand opener.** For a 3 to 5 s opener, a letter window that flicks real use moments and lands on the hero (recipe `../../recipes/letter-window/`).
