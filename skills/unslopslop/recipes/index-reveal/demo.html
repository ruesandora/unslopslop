    Index list reveal

    A big typographic index (brands, projects, categories) that turns into a picture browser on hover. The pointed row keeps full ink and opens a small square picture inside its own line; the other rows step back to a quieter tone; a preview beside the list fills with that row's pictures.

    Timing
    Row colour 220 ms and inline picture 260 ms, both cubic-bezier(.2, .8, .2, 1). The dim state starts on entering the list, not on entering a row, so moving between rows never flashes back to full ink.
    Contrast choice
    At rest every row has full ink. Only while one row is pointed do the others step back, and even then the quieter tone keeps about 3:1 on the ground, which is enough for type this large. A list that is pale at rest and only dark under the pointer is unreadable on touch screens, where nothing is ever pointed.
    How it is built
    Real links in a list. Pointer and focus set one class on the list and one on the row. The inline picture is a span whose width grows from 0 to the line height, so the word slides right instead of the picture covering it. The preview swaps two background images.
    Phones
    The preview is hidden and the list is a plain list of links; nothing depends on hover.
    Becomes slop when
    The rows are a fake client list, the pictures are random stock, or the whole page is built from hover lists.
