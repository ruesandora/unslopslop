Morphing icons

An icon that changes state by moving its own lines, so the eye follows one object instead of watching a swap. The three menu bars fold into a cross, the play triangle splits into two bars, an arrow bends into a check, sound waves cross into a mute mark, an eye closes along its lid.

How it is built
Every icon state is a list of strokes on a 24 unit grid, and the two states have the same number of strokes and points. A stroke that should vanish collapses to a point and fades. Curves are sampled into 9 to 13 points, which is smooth at icon sizes with round joins. A small loop eases every point from where it is now, so a second click mid-way turns back without a jump.
Measured starting values
Plain morph: spring of about 500 ms with no bounce (here a critically damped curve). Two-step morphs: 620 ms cubic-bezier(.65, 0, .35, 1). Blink: about 450 ms. Stroke width stays fixed in screen pixels.
Accessibility
Each icon is a real button with aria-pressed and a label that names the action, not the drawing. The state is never carried by motion alone.
Reduced motion
States switch instantly.
Becomes slop when
Icons morph on hover for no state change, every icon on the page bounces, or one icon family morphs while the rest of the set is static and drawn in another weight.
