# The template test

Question: if this page belonged to a different company, would anything have to change?

1. Cover or replace the brand name and logo with another company's in the same field (for a CRM page, use a competitor; for a bakery, a bank).
2. Read the headline, the first screen and the three main claims aloud.
3. If they still fit, the page is generic. A clean detector score does not prevent this: removing tells leaves a neutral page, not a specific one.
4. Fix by adding specificity, not decoration. Good sources: a real number with its source, the product's own vocabulary, a real screen or sample, a concrete step ("on day 3 it sends the polite reminder").
5. Optional second check: render the page in grayscale with the system font. If it is indistinguishable from a template, the layout carries no idea; give one block a distinct job.

Record the result in the report: "template test: passed because ..." or "failed, added ...".
